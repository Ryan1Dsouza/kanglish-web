# Alar dictionary subset

The companion `alar_conversational_glossary.json` is a derived dictionary subset
from Alar by V. Krishna / the Alar project, https://alar.ink/.

The dictionary data remains licensed under the Open Data Commons Open Database
License (ODbL) 1.0: https://opendatacommons.org/licenses/odbl/1-0/.
This data license is separate from the application source-code license.

Upstream data: https://github.com/alar-dict/data and
https://raw.githubusercontent.com/alar-dict/data/master/alar.yml.
Entry IDs, source, review status and license are retained in the JSON subset;
the preparation manifest records the imported source checksum and selection rules.
